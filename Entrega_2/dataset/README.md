# 2026_UTN_IAA_GrupoC
UTN FRBA - Inteligencia Artificial Avanzada - Grupo C - Identificación de especies vegetales nativas y exóticas

# Dataset

El dataset utilizado en esta entrega contiene 3.200 imágenes
correspondientes a ocho especies vegetales.

Las imágenes fueron obtenidas mediante la API de iNaturalist.

Distribución:

- Entrenamiento: 1.920 imágenes
- Validación: 480 imágenes
- Prueba: 800 imágenes

El archivo `manifest_inaturalist.csv` conserva la trazabilidad
de las observaciones utilizadas.

El dataset completo no se almacena en este repositorio debido
a su tamaño. Los notebooks permiten reconstruirlo a partir de
las fuentes originales.
